## ⚡ Features

- **Futuristic Cyberdeck HUD Interface**: Chamfered 45° polygon cards (`clip-path`), neon accents (Cyan, Violet, Magenta, Emerald), and CRT scanline overlays.
- **Top Telemetry Status Bar**: Real-time IST digital clock, geolocation coordinates (`Hyderabad, IN`), system status, and native Web Audio API synthesizer toggle.
- **Interactive Particle Network Canvas**: High-performance connected particle mesh reacting to mouse cursor proximity.
- **Interactive Command Line Terminal**: Built-in simulated BASH shell supporting commands like `help`, `about`, `skills`, `projects`, `missions`, `contact`, and `hire`.
- **Holographic AI Vision Scanner**: Simulated computer vision bounding box tracking demonstrating the *AI-Based Trash Classification Web App* (90% precision).
- **Segmented Energy Power Cells**: 10 discrete glowing LED cells per skill animating on scroll.
- **Classified Mission Dossiers**: Highlighting collegiate hackathons & workshops (*Hack Secure X*, *Generative AI Hackathon*, *GenAI Workshop*, *College Hackathon*).
- **Mobile First & Responsive**: Optimized from 375px mobile screens up to 4K displays.
- **Single File & Lightweight**: ~102 KB total footprint, fast loading, and deployable to any static host (GitHub Pages, Vercel, Netlify).

## 🚀 Live Hosting with GitHub Pages

1. Push this repository to your GitHub account.
2. Go to your repository's **Settings** &rarr; **Pages**.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.
